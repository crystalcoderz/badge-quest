## Ground rules (no cheating, no farming)

- **No alt accounts** — GitHub's ToS allows one free account per person, full stop.
- **No bought or traded stars** — that's "rank abuse" under GitHub's Acceptable Use Policies, and enforcement is real (purged accounts, deleted repos, revoked badges).
- **Real content only** — every issue here is a real issue, every PR changes real files. No empty no-op merges, no bulk self-merge spam.
- **Patience** — achievements are awarded asynchronously. Sometimes it takes days; there's even an open delay incident right now. If a badge doesn't show up, check `github.com/<you>?tab=achievements` before assuming the worst.

## 🤠 Quickdraw — close within 5 minutes

**Requirement:** close an issue or a pull request within 5 minutes of opening it. Single-tier badge (no bronze/silver/gold). Doing it in your own repo is the intended mechanic, not a loophole — the unlock dialog literally says *"Gitty up!"*

**Recipe (~2 minutes, solo):**
1. Open a real issue in a public repo you own (something you actually intend to fix).
2. Close it as *completed* within 5 minutes.
3. Reopening later doesn't revoke the badge.

## 😎 YOLO — merge with zero reviews

**Requirement:** merge a pull request that has no submitted code reviews. Single-tier badge. Failing checks don't matter (that's a myth); the only thing that matters is zero reviews — **including bot reviews**. CI linter apps that post reviews can silently block the badge, so use a fresh repo with no GitHub Apps installed.

**Recipe (~5 minutes, solo):**
1. Create a branch with a real change.
2. Open a PR — request no reviewers, install no review-bots.
3. Merge immediately. Any merge method works.

Both PRs in this repo (#2, #3) follow exactly this recipe.
